## Stack

Next.js (App Router) · TypeScript strict · Tailwind CSS · shadcn/ui · Framer Motion · lucide-react · React Hook Form + Zod · TanStack Query + Table · MSW · Vitest + Testing Library · Playwright.

## Zero-cost & language rules

- Site is **English only**: `<html lang="en">`, no i18n library, no RTL, no translated fields.
- No paid services. WhatsApp = floating "Chat on WhatsApp" button + admin "Open chat" button using free `https://wa.me/<digits>?text=<urlencoded>` links (number from `site-content.company.whatsapp` / contact's `whatsapp`). No WhatsApp API.
- Analytics: Cloudflare Web Analytics (free). Fonts self-hosted via `next/font` (no paid font CDN).
- Frontend runs in the same Docker stack on the free Oracle VM (`output: 'standalone'`, arm64). Don't use Vercel Hobby: its terms allow only non-commercial use.

## Contract rules

- Never hand-write API types or request functions. Use `@digixsquad/api-client` (generated by orval from `packages/contract/openapi.yaml`): `pnpm contract:gen`.
- Form validation starts from generated Zod (`@digixsquad/api-client/zod`, e.g. `CreateHireRequestBody`). Add UI-only rules with `.superRefine` (GOVT ⇒ procurement_mode, SQUAD ⇒ squad_slug, SINGLE_ROLE ⇒ 1 item).
- Until the API exists, mock with **MSW** using `packages/contract/seed/*.json` as fixture data.
- Static marketing copy (hero, about, mission, vision, values, FAQs) comes from `getSiteContent` with the seed JSON as build-time fallback. Don't hardcode copy in components.

## Home intro + hero (approved direction)

Reference: `docs/prototypes/intro.html` (open in a browser; Skip/Replay buttons are prototype-only). Port it to `apps/web/src/components/home/IntroSplash.tsx` + `HomeHero.tsx` with Framer Motion. Keep timings and layout.

| Time      | Step                                                                                                                                                                                                                                                    |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0–1.9s    | **Popup:** chamfered dark panel with orange edge pops in (scale .4→1.06→1, slight rotate), DS logo with glow, scan line, "Assembling your squad" + progress bar                                                                                         |
| 1.9–2.45s | **Burst:** panel scales ×2.6 + blur + fade, diagonal orange light sweep                                                                                                                                                                                 |
| 2.1s+     | **Hero:** orange halo grows, chamfered hexagon frame fades in, founder portrait rises from below (blur → sharp) in the **center**; **"DIGITAL"** slides in from the left (white), **"SQUAD"** from the right (orange gradient), letter-spacing tightens |
| +1.2s     | Navbar drops in; tagline + "Hire a Squad" / "Explore Roles" fade up over a bottom shade                                                                                                                                                                 |

- Assets: `brand/founder.webp` (background removed, 642×1100) · full-res `brand/founder-cutout.png` · `brand/logo.webp`. Use `next/image` with `priority`.
- Plays **once per session** (`sessionStorage` key `ds_intro_seen`, wrapped in try/catch). Click or Esc skips. `prefers-reduced-motion` → show the final hero right away.
- Mobile (< 820px): DIGITAL top-left, SQUAD under it right-aligned, portrait below, CTAs stacked at the bottom.
- Must not hurt LCP: hero HTML renders server-side underneath the overlay; overlay is a client component.
- Portrait alt text and the founder's name/title come from site content (ask the client for the name and designation).
